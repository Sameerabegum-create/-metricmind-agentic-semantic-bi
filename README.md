# MetricMind

## Agentic Semantic BI Engine

MetricMind is an analytics project designed to provide
business insights through a governed semantic layer.

## Domain

Enterprise Analytics & Agentic AI

## Main Objective

The system will allow users to ask business questions
in natural language and receive analytical results using
defined business metrics.

## Planned Business Metrics

- Revenue
- Cost
- Margin

## Planned Dimensions

- Time
- Geography

## Technology

- Python
- SQL
- dbt
- Cube.dev
- LangChain
- LLM
- Next.js
- Snowflake / Databricks
